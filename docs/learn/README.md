# راهنمای یادگیری Dockra

[English](en/README.md) · **فارسی**

این راهنما برای **مطالعه** نوشته شده، نه برای مرجع سریع. هدفش این است که با خواندن کد واقعی همین پروژه، مفاهیم مهندسی پلتفرم و نرم‌افزار را عمیق یاد بگیرید: یک PaaS واقعی چطور کد را می‌گیرد، می‌سازد، بدون قطعی جایگزین می‌کند، ایزوله نگه می‌دارد و وقتی چیزی خراب می‌شود چه می‌کند.

> مرجع فنی دقیق (انگلیسی): [architecture.md](../architecture.md)، [deployment-lifecycle.md](../deployment-lifecycle.md)، [security.md](../security.md) و [api.md](../api.md).

## پیش‌نیاز

- Python و مقدمات Django (model، view، migration)
- JavaScript/TypeScript و مقدمات React
- آشنایی با خط فرمان لینوکس، HTTP و Git
- آشنایی اولیه با Docker (image، container، volume)

لازم نیست Traefik، BuildKit، cgroup، WebSocket یا Tailwind بلد باشید؛ در فصل‌ها توضیح داده می‌شوند.

## مسیر پیشنهادی مطالعه

1. فصل ۱ را بخوانید و پروژه را با Quick start در README اجرا کنید (`seed_demo` داده‌ی نمونه می‌سازد). در پنل بچرخید.
2. فصل‌های ۲ تا ۵ (هستهٔ پلتفرم) را به ترتیب بخوانید و فایل‌هایی را که اسم برده می‌شود کنارش باز کنید.
3. فصل ۶ را با دقت بخوانید؛ بعد فهرست «چیزهایی که محافظت نمی‌شوند» را در [security.md](../security.md) ببینید.
4. فصل‌های ۷ تا ۱۱ و ۱۳ را به هر ترتیبی که علاقه دارید.
5. فصل ۱۲ را آخر بخوانید و تست‌ها را خودتان اجرا کنید؛ یک تست را عمداً بشکنید.
6. فصل ۱۴ را بعد از فصل ۱۲ بخوانید؛ داستان‌هایش به فصل‌های قبلی ارجاع می‌دهند.

هر فصل با چند **تمرین** تمام می‌شود. تمرین‌ها را واقعاً انجام دهید؛ بیشترین یادگیری همان‌جاست.

## نحوه‌ی خواندن کد

- **از قرارداد شروع کنید، نه از جزئیات.** اول [api.md](../api.md) را ببینید، بعد view مربوط.
- **مسیر یک درخواست را دنبال کنید.** مثلاً «استقرار» را از `cmd_deploy` در `cli/dockra.py` تا `DockerDriver._launch` در `api/engine/drivers.py` دنبال کنید.
- **تست‌ها مستندات اجرایی‌اند.** وقتی نمی‌دانید یک تابع دقیقاً چه می‌کند، تستش را در `api/engine/test_*.py` بخوانید.
- **با درایور fake بازی کنید.** همه‌چیز بدون Docker کار می‌کند؛ با `DOCKRA_EAGER=0` و `run_worker` می‌توانید صف را با چشم ببینید.
